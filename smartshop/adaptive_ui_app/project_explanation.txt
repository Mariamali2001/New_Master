1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
The "Adaptive E-Commerce UI Generator" is a Streamlit-based web application designed
to help UI/UX designers and researchers derive data-driven, personalized interface
guidelines based on user demographics, context (device, mood, motivation), and 
psychometric personality traits.

Instead of generic design systems, this project analyzes real user survey data 
(data/E-Commerce.csv) to automatically recommend optimal UI layouts, typography,
color schemes, navigation patterns, and information density for specific target personas.


2. ARCHITECTURE & CORE MODULES
--------------------------------------------------------------------------------
- Home.py / utils.py:
  * Application entry point.
  * Loads the default survey dataset (`data/E-Commerce.csv`) or accepts user-uploaded CSVs.
  * Cleans data: Drops empty rows AND filters out low-quality responses using 5 attention checkers (`check1` through `check5`).
    - Correct criteria: `check1`, `check2`, `check4`, `check5` = 3, and `check3` = 'Rounded Corners'.
    - Retention rule: Responses with at least 4 out of 5 correct checks are retained (score >= 4/5). Records with 2 or more errors (< 4/5) are automatically dropped.
  * Stores the filtered dataset in Streamlit global session state (`st.session_state`).

- utils.py:
  * Backend engine for data processing, rule generation, explainable ML, and clustering.
  * Feature Categorization (All CSV dataset elements mapped):
    - Demographics: Age Group, Gender, Education Level.
    - Context & Shopping Behavior: Primary Persona, Primary Device, Shopping Motivation,
      Decision Speed, Current Mood, Price Sensitivity, Review Importance, Brand Loyalty,
      Social Proof Influence.
    - Personality Traits: Introversion, Trust, Low Conscientiousness, Emotional Stability,
      Low Openness, Extraversion, Agreeableness (reverse), Conscientiousness, Neuroticism, Openness.
    - UI Preferences (Targets): Typography, Button Styles, Navigation, Hero Banner,
      Recommendation Type, Social Proof Display, Urgency Pref, Checkout Style, Form Field Style,
      Product Description Length, Desktop/Mobile Grid Layouts, Info Density, Image/Text Ratio,
      Search Visibility, Category Display, Price Display, Filter Location, Quick View, Review Display.


- pages/1_Guideline_Explorer.py:
  * Main interactive dashboard.
  * Filters data based on sidebar inputs (Persona, Device, Mood, Personality Sliders).
  * Displays Primary Guidelines (Structure/Navigation) and Secondary Guidelines (Visuals/Aesthetics).
  * Includes Comparison Mode (Mobile vs. Desktop) and SHAP-based Explainability panels.

- Other Pages:
  * UI Variant Discovery: Discovers latent design patterns using K-Means clustering.
  * Methodology: Explains the statistical and ML pipeline to users.
  * Data Exploration & Visualization (Page 2): 
    - Trait Distributions, Preferences by Context, Cross-Analysis.
    - **Choice Frequency Counts (New Tab)**: Interactive inspector displaying the total number of records and percentage breakdown for each response option across any column.



3. HOW INFLUENCE IS CALCULATED (EXPLAINABILITY & STABILITY)
--------------------------------------------------------------------------------
The project calculates "influence" and preference strength using a 3-part methodology:

A. SHAP (SHapley Additive exPlanations) Influence:
   - Function: `get_shap_explanation()` in utils.py
   - When an "Explain" button is clicked for a UI component (e.g., Font Style or Navigation):
     1. Encodes categorical inputs using LabelEncoder.
     2. Trains a Random Forest Classifier (`train_model`) with 100 trees to predict 
        the target UI preference using all user features (demographics, context, traits).
     3. Computes SHAP values via `shap.TreeExplainer(model)`.
     4. Calculates the mean absolute SHAP value across all samples and output classes:
        SHAP_Importance = Mean(|SHAP_values|)
     5. The top 3 features with the highest SHAP scores are presented as the primary 
        drivers/influencers behind why users prefer that specific UI element.

B. Feature Importance (Fallback):
   - Function: `calculate_feature_importance()` in utils.py
   - Extracted directly from Random Forest `model.feature_importances_` (Mean Decrease in Impurity).
   - Serves as a backup if SHAP array dimensions are uniform or singular.

C. Statistical Confidence & Bootstrapping Stability:
   - Function: `get_guideline()` & `calculate_stability()` in utils.py
   - Recommendation: Winning UI preference determined by majority vote in the filtered segment.
   - Confidence Score: (Count of top choice) / (Total filtered users).
   - Stability Score: Performs Bootstrapping (resampling data 20 times with replacement).
     Checks how often the top choice remains the winner across resampled variations.
     * > 80%  -> High Confidence
     * 50-80% -> Moderate Confidence
     * < 50%  -> Exploratory


4. CLUSTERING & UI VARIANTS
--------------------------------------------------------------------------------
- Function: `cluster_ui_preferences()` in utils.py
- Uses K-Means Clustering on encoded UI target preferences to partition users into 
  distinct "UI Variant" archetypes (e.g., Minimalist vs. Information-Rich shoppers).
- Computes dominant profile traits and bundled UI recommendations per cluster.
