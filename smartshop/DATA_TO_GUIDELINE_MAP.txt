How to read:
  Survey column  = field name in clean_dataset.csv
  JSON file      = which repository file stores the decision
  JSON key       = token key used by Adaptive Engine / Final UI Configuration
  Survey majority= most common answer in the CSV (with %)
  JSON default   = value currently stored in defaults files
  Strength       = STRONG (≥45%) / MODERATE (≥30%) / WEAK/SPLIT (<30%)

7) CONTEXT-ONLY SURVEY FIELDS (not UI token keys)
   Used by Context Builder / experiment save — not merged as UI tokens
------------------------------------------------------------------------------------------------
  age_group / answers.age            → Context.user.age                         (Questionnaire age)
  gender                             → Context.user.gender                      (Questionnaire gender)
  primary_device                     → Context.device                           (detectDeviceClient() + survey)
  primary_persona                    → Context.persona / surveyPersona          (Mapped via SURVEY_PERSONA_TO_GUIDELINE)
  current_mood                       → Context.mood.selfReported                (Research field; live engine uses detected)
  Extraversion..Openness scores      → Context.traits.*.score                   (TIPI continuous 1–5)
  *_Level                            → Context.traits.*.level                   (High/Medium/Low → High/Low for lookup)
  shopping_motivation etc.           → answers / experiment export              (Admin Excel, not Adaptive Engine tokens)

------------------------------------------------------------------------------------------------
8) ADAPTIVE ENGINE MERGE ORDER (which JSON wins)
------------------------------------------------------------------------------------------------
  1. global_defaults.json
  2. desktop_defaults.json  OR  mobile_defaults.json
  3. persona_lookup.json[persona].overrides   (explicit keys only)
  4. mood_lookup.json[mood].overrides         (wins over persona on same key)
  5. trait_lookup.json[trait][High|Low].nudges (additive; separate nudges map)

Alternates also in folder (not used by runtime if lookup_* preferred):
  persona_overrides.json, mood_overrides.json, trait_modifiers.json
  See manifest.json required_for_website vs alternative_source_files
